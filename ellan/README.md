# Ellan — futura sezione del sito

Struttura predisposta per la riorganizzazione di Ellan dopo Lucca Comics & Games 2026.

La pagina pubblica attuale resta `/ellan.html`. Nessuna nuova pagina pubblica è attivata in questa fase.

- `atlante/`: mappa interattiva e dati territoriali
- `gazzettini/`: pagine web dei regni e territori
- `manuali/`: guida al mondo e approfondimenti
- `naturalistico/`: flora, fauna e creature
- `cronache/`: racconti
- `mappe/`: cartografia
- `images/`: illustrazioni e risorse web ottimizzate
- `pdf/`: eventuali PDF locali, privilegiando GitHub Releases per i documenti ufficiali
- `css/`: fogli di stile
- `js/`: funzionalità del portale

I percorsi sono preparatori, non comportano migrazioni dei materiali esistenti.
